# Rule 12

ARCP Rule 12 governs defenses and objections at the pleading stage, including motions raised before a responsive pleading and the preservation or waiver of defenses.  A Rule 12 ruling and a subject-matter jurisdiction ruling can each end a case before any evidence is taken, which is why this directory keeps them together.  The judge must test the sufficiency of what is pleaded without deciding whether it is true, and that line is the boundary between Rule 12 and Rule 56.  The failure with consequences is disbelieving a pleaded fact, because it turns a pleading test into a factual one and closes a claim entitled to proceed.
