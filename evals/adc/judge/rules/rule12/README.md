# Rule 12

Rule 12 evals test pleading-stage dismissal and subject-matter jurisdiction screening.  The current suite covers complaint sufficiency, jurisdiction defects, amendment posture, prejudice, and the boundary between pleading facts and summary-judgment evidence.  It keeps the dismissal and jurisdiction rows together because both decisions can close a case before trial.
