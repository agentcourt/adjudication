# Rule 56

Rule 56 evals test summary-judgment decisions.  The current suite focuses on false grants, genuine factual disputes, credibility issues, competing inferences, element-specific failures, unsupported damages theories, and authentication disputes.  It is the main pretrial merits-disposition eval because an erroneous grant ends a claim before trial.
