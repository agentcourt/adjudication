# Rule 58

ARCP Rule 58 requires every judgment to be set out in a separate document and fixes when judgment is entered.  Entry is a state-consistency step rather than a merits decision: the verdict or the bench findings already determined the result, and the judgment must reflect it.  The judge must use the amount the proceeding determined, wait until there is a result to enter, and produce the expected status transition.  The failure with consequences is a judgment inconsistent with the verdict, because it substitutes the judge's result for the factfinder's.
