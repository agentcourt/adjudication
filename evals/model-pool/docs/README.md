# Model-Pool Documentation

This directory contains stable documentation for the model-pool eval system.  Operational commands and scoring references live in the manual and rubric, while this directory keeps focused notes on sampling, model inventory, legacy pool generation, and historical planning.  Generated run summaries stay under ignored `results/` directories; this index covers committed documents.
