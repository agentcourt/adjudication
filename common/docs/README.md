# Common Documentation

`common/docs/` contains documentation for shared assets and tools used by more than one adjudication system.  System manuals remain under `adc/`, `arb/`, and `arbd/`.  Model and provider-endpoint evaluation, clustering, graphing, and pool-selection documentation lives under [Model Pool](../../model-pool/README.md).

Container documentation lives in [Pi Container Image](../pi-container/README.md).  Tool documentation lives in [Common Tools](../tools/README.md).  Merits-graph skill notes live in [Merits Graph Skill](../tools/merits-graph-skill.md).
