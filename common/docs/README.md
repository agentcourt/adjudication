# Common Documentation

`common/docs/` contains documentation for shared assets and tools used by more than one adjudication system.  System manuals remain under `adc/`, `arb/`, and `arbd/`.  Shared docs belong here when the same file supports more than one procedure.

| Document | Use |
| --- | --- |
| [Jury And Council Pool Generation](jury-pool-generation.md) | Persona corpus, embedding, clustering, and request-spec pool generation. |

Container documentation lives in [Pi Container Image](../pi-container/README.md).  Tool documentation lives in [Common Tools](../tools/README.md).  Merits-graph skill notes live in [Merits Graph Skill](../tools/merits-graph-skill.md).
