# Model-Pool Documentation

This directory contains reference documentation for the model-pool system.  Operational commands and scoring references live in the manual and rubric, while this directory keeps focused notes on the sampling procedure and on OpenRouter provider-endpoint identity.  Generated run summaries stay under ignored `results/` directories; this index covers committed documents.
