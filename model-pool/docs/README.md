# Model-Pool Documentation

This directory contains reference documentation for the model-pool eval system.  Operational commands and scoring references live in the manual and rubric, while this directory keeps focused notes on sampling, model inventory, and the legacy CSV pool pipeline.  Generated run summaries stay under ignored `results/` directories; this index covers committed documents.
